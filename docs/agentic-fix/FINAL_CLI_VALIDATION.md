## Claude Code

Использован документированный неинтерактивный режим `--print --output-format stream-json`. Команда запускалась в отдельной временной папке через локальный Bridge и модель `deepseek-reasoner`. Были включены `--safe-mode`, `--bare`, отключено сохранение сессии, а список встроенных инструментов ограничен только `Read`.

Безопасная форма команды без значений локальной авторизации и полного пути:

```powershell
claude.cmd --print --output-format stream-json --verbose --no-session-persistence --safe-mode --bare --no-chrome --disable-slash-commands --tools Read --allowedTools Read --permission-mode dontAsk --model deepseek-reasoner "<read-only task>"
```

Результат:

- код завершения: `0`;
- Claude Code дважды вызвал встроенный `Read` с разными call id;
- первый tool result содержал значение из `marker.txt`;
- после первого результата модель продолжила работу и вызвала `Read` для `second-marker.txt`;
- второй tool result содержал значение из второго файла;
- после второго результата модель вернула финальный текст с обоими точными маркерами в требуемом порядке;
- Bash, Write, Edit, MCP, skills и сетевые инструменты не были доступны.

## OpenCode

Использован документированный неинтерактивный режим `run --format json`. `OPENCODE_CONFIG` указывал на актуальный проектный `opencode.json`; глобальная конфигурация не изменялась. Временный per-process `OPENCODE_CONFIG_CONTENT` был предварительно подтверждён локальной командой `debug config` и устанавливал `permission: {"*":"deny","read":"allow"}`. Запуск выполнялся с `--pure`, моделью `deepseek-web/deepseek-reasoner` и агентом `build`.

Безопасная форма команды без полного пути:

```powershell
$env:OPENCODE_CONFIG="<repository>\opencode.json"
$env:OPENCODE_CONFIG_CONTENT='{"permission":{"*":"deny","read":"allow"}}'
opencode.cmd run --pure --format json --model deepseek-web/deepseek-reasoner --agent build --dir "<temporary folder>" "<read-only task>"
```

Результат:

- код завершения: `0`;
- OpenCode дважды выполнил инструмент `read` с разными call id;
- оба события инструмента завершились со статусом `completed` и вернули содержимое соответствующих файлов;
- после первого результата модель продолжила работу и запросила чтение второго файла;
- после второго результата модель вернула финальный текст с обоими точными маркерами в требуемом порядке;
- временное правило запрещало все инструменты, кроме `read`;
- глобальная конфигурация OpenCode не изменялась.

## Целостность временных файлов

До запуска CLI были сохранены SHA-256 четырёх marker-файлов. После обоих тестов все четыре hashes совпали. В каждой тестовой папке остались только `marker.txt` и `second-marker.txt`; дополнительных файлов и каталогов не появилось. После проверки созданные временные папки и отдельный временный config-root OpenCode были удалены.

Репозиторий после CLI-запусков остался без новых файлов и изменений.

## Оставшиеся ограничения

- Bridge использует внутренний DeepSeek Web API, который может измениться независимо от проекта.
- Проверка покрывает встроенные read-only инструменты установленных версий Claude Code и OpenCode, но не все MCP-серверы, skills и сторонние плагины.
- `count_tokens` остаётся локальной приблизительной оценкой, а не официальным токенизатором.
- После обновления любого CLI или DeepSeek Web существенную live-проверку следует повторить вручную.
