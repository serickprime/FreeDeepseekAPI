## Вывод

Claude Code 2.1.217 через текущий Bridge способен надёжно выполнить обязательный `Read`, вернуть связанный `tool_result` и получить точный неизвестный заранее маркер, когда разрешён только один инструмент и ответ невозможно вывести из пользовательского сообщения.

Результат предыдущего этапа с финальным content без tool call следует классифицировать как отдельный пропуск инструмента моделью в том конкретном запросе, а не как исчезновение tools или общую недоступность `Read`.

Повтор длинного compaction-теста теперь технически обоснован как отдельный этап: минимальная обязательная цепочка `Read` → `tool_result` подтверждена live. Повтор нельзя запускать автоматически; он требует отдельного разрешения и должен начинаться с такого же однозначного одиночного `Read` перед накоплением контекста.

Изменять Bridge, добавлять retries, capability cache, восстановление allowlist или постоянную upstream-сессию по результатам этой проверки не требуется.
