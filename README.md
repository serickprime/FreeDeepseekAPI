# DeepSeek Bridge — простое подключение DeepSeek к CLI-агентам

DeepSeek Bridge — локальная программа для Windows 10/11. Она использует **ваш собственный вход в веб-версию DeepSeek** и открывает на вашем компьютере совместимый API по адресу `http://127.0.0.1:9655`.

Благодаря этому можно использовать DeepSeek Web в Claude Code, OpenCode, Open WebUI, LiteLLM и других программах, которые умеют работать с OpenAI- или Anthropic-совместимыми API. Программа не создаёт аккаунты, не обходит CAPTCHA/2FA и не выполняет команды агента сама: она только передаёт запросы между вашим агентом и DeepSeek.

> Это не официальный DeepSeek API. Программа обращается к внутреннему Web API, который DeepSeek может изменить, ограничить или отключить в любой момент.

## Что понадобится

- Компьютер с Windows 10 или Windows 11 и доступом в интернет.
- Ваш обычный аккаунт DeepSeek.
- [Google Chrome](https://www.google.com/chrome/download-chrome) — нужен для безопасного входа в DeepSeek через отдельный профиль.
- [Node.js LTS](https://nodejs.org/en/download), версия 20 или новее. Выбирайте кнопку **LTS**, а не Current.
- По желанию: Claude Code или OpenCode. Без них можно подключать другие API-клиенты.

Chrome устанавливается обычным установщиком с подтверждением Windows. [Инструкция Google](https://support.google.com/chrome/answer/95346?hl=EN-GB) описывает этот процесс для Windows.

## 1. Как скачать программу

### Вариант A — проще всего: ZIP-архив

1. Войдите в GitHub под аккаунтом, которому доступен репозиторий.
2. Откройте [страницу проекта](https://github.com/serickprime/FreeDeepseekAPI).
3. Нажмите зелёную кнопку **Code** → **Download ZIP**.
4. Откройте скачанный архив, нажмите «Извлечь все».
5. Выберите обычную папку, например `D:\AI\DeepSeekBridge`.

Не распаковывайте программу в `C:\Program Files` и не размещайте её в публичной папке: там могут возникать лишние запросы прав доступа.

### Вариант B — через Git

Этот вариант удобен для получения будущих обновлений. Установите Git for Windows, откройте PowerShell и выполните:

```powershell
cd D:\AI
git clone https://github.com/serickprime/FreeDeepseekAPI.git DeepSeekBridge
```

После этого папка программы будет: `D:\AI\DeepSeekBridge`.

## 2. Установка Node.js и проверка

1. Скачайте LTS-установщик Node.js по [официальной ссылке](https://nodejs.org/en/download).
2. Запустите установщик и оставьте стандартные галочки.
3. Закройте все окна PowerShell, затем откройте новое.
4. Выполните:

```powershell
node --version
npm --version
```

Первая команда должна вывести версию `v20` или выше. На момент написания актуальная LTS-ветка — Node.js 24; проект совместим с Node.js 20+. [Страница загрузки Node.js](https://nodejs.org/en/download)

Если написано «node не является внутренней или внешней командой», перезагрузите компьютер или переустановите Node.js с включённой опцией добавления в PATH.

## 3. Открытие PowerShell в папке программы

1. Откройте папку, куда распаковали программу.
2. Щёлкните по пустому месту папки правой кнопкой мыши.
3. Выберите «Открыть в Терминале» или «Открыть окно PowerShell здесь».

Можно также открыть адресную строку Проводника, написать `powershell` и нажать Enter.

Проверьте, что вы в правильной папке:

```powershell
Get-Location
```

В выводе должен быть путь к `DeepSeekBridge` или `FreeDeepseekAPI`.

> У проекта нет обязательных внешних npm-зависимостей, поэтому обычно команда `npm install` не нужна. Для первой самопроверки достаточно `npm test`.

## 4. Первая проверка программы

В PowerShell из папки программы выполните:

```powershell
npm test
```

Успешный результат заканчивается строкой вроде `pass 20`. Этот тест не использует ваш DeepSeek-аккаунт и не отправляет запросы в интернет.

## 5. Вход в DeepSeek — выполняется один раз

В той же папке выполните:

```powershell
npm run auth
```

Далее:

1. Откроется отдельный профиль Chrome с сайтом DeepSeek.
2. Войдите в **свой** аккаунт как обычно.
3. CAPTCHA и двухфакторную проверку проходите самостоятельно.
4. В чате DeepSeek отправьте ровно сообщение `ok`.
5. Дождитесь, пока появится ответ DeepSeek.
6. Вернитесь в PowerShell и нажмите Enter.

После успеха появится файл `deepseek-auth.json`. Он хранит данные вашей сессии, а не логин или пароль.

> `deepseek-auth.json` даёт доступ к вашей сессии. Никому его не отправляйте, не добавляйте в облачное хранилище и не публикуйте. Файл уже исключён из Git.

Проверьте вход:

```powershell
npm run doctor
```

Нужен результат без ошибок. Если сессия закончилась в будущем, просто повторите `npm run auth`.

## 6. Самый простой ежедневный запуск

1. Дважды нажмите [START_DEEPSEEK.cmd](START_DEEPSEEK.cmd).
2. В браузере откроется панель: `http://127.0.0.1:9655/setup`.
3. Убедитесь, что вверху написано «API готов», а в первом блоке — «Подключено».
4. При необходимости нажмите «Запустить диагностику».

Не закрывайте окно терминала/сервера, пока пользуетесь CLI-агентом. Если панель уже открыта, но обновления не видны, нажмите `Ctrl+F5`.

Альтернатива для PowerShell:

```powershell
npm run ui
```

Обычный запуск сервера без панели:

```powershell
npm start
```

Проверка, что сервер работает:

```powershell
Invoke-RestMethod http://127.0.0.1:9655/health
```

Ожидаемый ответ: `status` со значением `ok`.

## 7. Как пользоваться панелью

### Выберите модель

В панели доступны только проверенные сейчас режимы DeepSeek Web:

| Режим | Когда выбирать |
| --- | --- |
| `deepseek-chat` | Короткие обычные ответы без reasoning и поиска. |
| `deepseek-reasoner` | Рекомендуемый вариант для кода, сложных задач и инструментов CLI-агентов. |
| `deepseek-chat-search` | Обычные ответы со встроенным веб-поиском DeepSeek. |
| `deepseek-reasoner-search` | Сложные задачи с reasoning и веб-поиском. |

`deepseek-expert` и `deepseek-v4-pro` намеренно отключены: в последней живой проверке Web API вернул для них пустой результат. Это честнее, чем выдавать неработающий alias за другую модель.

### Выберите папку проекта

В поле «Папка проекта» укажите папку, с файлами которой должен работать агент. Например:

```text
D:\Мои проекты\Сайт-визитка
```

Можно вставить путь вручную или нажать «Выбрать папку…» и выбрать каталог в системном окне Windows. После выбора Claude Code/OpenCode откроется именно в этой папке, сможет читать и менять её файлы.

Если системное окно не появилось сразу, проверьте панель задач: Windows может вывести его поверх или рядом с браузером. Путь можно всегда вставить вручную. Несуществующая папка не будет принята.

### Запустите агента

Нажмите «Запустить Claude Code» или «Запустить OpenCode». Откроется новое окно терминала уже в выбранной папке и с выбранной моделью. Можно писать задания агенту обычным языком, например:

```text
Посмотри структуру этого проекта и объясни, как его запустить.
```

или:

```text
Найди ошибку в форме входа и предложи безопасное исправление. Сначала покажи план.
```

Агент может запрашивать разрешение на изменение файлов или запуск команд. Читайте такие запросы перед подтверждением.

## 8. Установка Claude Code

Claude Code нужен только если вы хотите пользоваться кнопкой «Запустить Claude Code».

Откройте обычный PowerShell и выполните официальную команду установки:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Затем закройте PowerShell, откройте новый и проверьте:

```powershell
claude --version
```

После установки вернитесь в панель DeepSeek Bridge и обновите страницу. Кнопка Claude Code станет активной.

На нативном Windows полезно также установить Git for Windows: тогда Claude Code сможет использовать Git Bash. Без Git он использует PowerShell. Официальные требования и способы установки Claude Code описаны в [документации Anthropic](https://code.claude.com/docs/en/setup).

Для ручного запуска без панели, из папки вашего проекта:

```powershell
$env:ANTHROPIC_BASE_URL="http://127.0.0.1:9655"
$env:ANTHROPIC_AUTH_TOKEN="local-key"
$env:CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY="1"
claude --model deepseek-reasoner
```

`local-key` — не настоящий ключ Anthropic; это локальное значение для подключения к Bridge.

## 9. Установка OpenCode

OpenCode нужен только если вы хотите пользоваться кнопкой «Запустить OpenCode».

В PowerShell выполните:

```powershell
npm install -g opencode-ai
```

Проверьте установку:

```powershell
opencode --version
```

Вернитесь в панель DeepSeek Bridge и обновите страницу. Кнопка OpenCode станет активной.

При запуске из панели OpenCode автоматически получает конфигурацию этого прокси и работает в выбранной вами папке. Файл [opencode.json](opencode.json) в ваш проект копировать не нужно.

OpenCode официально поддерживает установку через npm в Windows; его документация также рекомендует WSL для некоторых сценариев, но этот проект рассчитан на обычный Windows PowerShell. [Документация OpenCode](https://opencode.ai/en/docs)

## 10. Подключение других программ

Для Open WebUI, LiteLLM и других OpenAI-совместимых клиентов используйте:

```text
Base URL: http://127.0.0.1:9655/v1
```

Список доступных моделей можно открыть по адресу:

```text
http://127.0.0.1:9655/v1/models
```

Поддерживаемые API:

- OpenAI Chat Completions: `POST /v1/chat/completions`
- OpenAI Responses: `POST /v1/responses`
- Anthropic Messages: `POST /v1/messages`
- Проверка состояния: `GET /health` и `GET /readyz`

`stream: true` поддерживается. Tool calls проверяются и возвращаются клиентскому агенту; Bridge не запускает инструменты, команды и файлы от имени модели.

## Если что-то не работает

| Проблема | Что сделать |
| --- | --- |
| Панель пишет «Нужен вход» или `doctor` выдаёт ошибку | Запустите `npm run auth` заново. |
| Кнопка агента отключена | Установите Claude Code или OpenCode, затем нажмите `Ctrl+F5` в панели. |
| Агент открылся не в той папке | Проверьте поле «Папка проекта», вставьте полный путь и запустите агент снова. |
| Порт 9655 занят | Закройте старые окна `node`/Bridge, затем снова запустите `START_DEEPSEEK.cmd`. |
| `node` или `npm` не найдены | Перезапустите PowerShell либо переустановите Node.js LTS. |
| Модель Expert/V4 Pro недоступна | Это ожидаемо: используйте один из четырёх доступных режимов. |
| Ошибка 401/403 от DeepSeek | Сессия закончилась: выполните `npm run auth`. |
| Ошибка 429 | DeepSeek временно ограничил запросы. Подождите и повторите позже. |

Для диагностики всегда можно выполнить:

```powershell
npm run doctor
```

## Безопасность и приватность

- Сервер по умолчанию слушает только ваш компьютер: `127.0.0.1:9655`.
- Телеметрии нет: токены, cookie, исходный код и статистика не отправляются сторонним сервисам.
- При внешнем `HOST` программа требует сильный `PROXY_API_KEY`; не открывайте порт 9655 в интернет без необходимости.
- Не публикуйте `deepseek-auth.json`, `.chrome-profile-deepseek` и `.env`.
- Храните папку программы в месте, к которому нет доступа у посторонних пользователей Windows.

## Обновление и удаление

Если скачивали ZIP, скачайте свежий ZIP и повторите настройку. Если использовали Git:

```powershell
git pull
```

После обновления перезапустите Bridge и выполните `npm test`.

Чтобы полностью удалить программу, сначала закройте Bridge и окна агентов, затем удалите папку программы. Вместе с ней будет удалён `deepseek-auth.json`; при повторной установке понадобится снова войти в DeepSeek.

## Для продвинутых пользователей

- `GET /v1/model-capabilities` показывает возможности и отключённые aliases.
- `GET /v1/sessions` показывает локальные сессии.
- `POST /reset-session` сбрасывает сессию.
- В `.env.example` перечислены безопасные локальные настройки: порт, лимит тела запроса, timeout и TTL сессии.
