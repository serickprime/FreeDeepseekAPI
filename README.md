# DeepSeek Bridge

DeepSeek Bridge позволяет подключить ваш обычный аккаунт DeepSeek к Claude Code, OpenCode и другим программам для работы с кодом. Всё работает только на вашем компьютере: Bridge открывает локальную панель управления и не требует API-ключа DeepSeek.

> Это не официальный DeepSeek API. Программа использует внутреннюю веб-версию DeepSeek, поэтому сервис может в будущем изменить или ограничить её работу.

## Что понадобится

- Windows 10 или Windows 11;
- ваш аккаунт DeepSeek;
- Google Chrome;
- Node.js LTS (версии 20 или новее);
- Claude Code или OpenCode — только если хотите пользоваться ими.

Node.js можно скачать с [официальной страницы](https://nodejs.org/en/download). Выберите **LTS** и установите его со стандартными настройками. Chrome можно скачать [здесь](https://www.google.com/chrome/download-chrome).

## Как скачать программу

1. Войдите в GitHub под аккаунтом, которому доступен [репозиторий DeepSeek Bridge](https://github.com/serickprime/FreeDeepseekAPI).
2. Нажмите зелёную кнопку **Code**.
3. Нажмите **Download ZIP**.
4. Откройте скачанный ZIP-архив и нажмите «Извлечь все».
5. Распакуйте, например, в папку `D:\AI\DeepSeekBridge`.

Не распаковывайте программу в `C:\Program Files`: Windows может попросить лишние права доступа.

## Первый запуск

1. Откройте папку распакованной программы.
2. Дважды нажмите [START_DEEPSEEK.cmd](START_DEEPSEEK.cmd).
3. Подождите: браузер откроет панель DeepSeek Bridge.
4. В первом блоке нажмите **Войти в DeepSeek**.
5. Откроется отдельное окно Chrome. Войдите в свой DeepSeek-аккаунт как обычно, самостоятельно пройдите CAPTCHA/2FA и отправьте в чате сообщение `ok`.
6. Дождитесь ответа DeepSeek, затем вернитесь в открывшееся окно терминала и нажмите Enter.
7. Вернитесь в панель и нажмите **Запустить диагностику**. Должен появиться успешный результат.

После этого Bridge готов к работе. При следующих запусках снова достаточно дважды нажать `START_DEEPSEEK.cmd`.

## Как открыть Claude Code или OpenCode через панель

1. Откройте панель. Если она не открылась сама, перейдите по адресу: `http://127.0.0.1:9655/setup`.
2. В поле **Модель DeepSeek Web** выберите модель:

   - **DeepSeek Reasoner** — рекомендуемый вариант для кода и сложных задач;
   - **DeepSeek Chat** — для простых быстрых вопросов;
   - варианты **+ Search** — когда агенту нужен поиск в интернете.

3. В поле **Папка проекта** укажите папку, с которой будет работать агент. Например: `D:\Мои проекты\Сайт`.
4. Либо нажмите **Выбрать папку…** и выберите её в окне Windows.
5. Нажмите **Запустить Claude Code** или **Запустить OpenCode**.

Откроется новое окно терминала уже в выбранной папке. Теперь просто напишите агенту задачу, например:

```text
Посмотри этот проект и объясни, как его запустить.
```

или:

```text
Найди ошибку и предложи исправление. Сначала покажи план.
```

Агент сможет читать файлы в выбранной папке и может спросить разрешение на изменение файлов или запуск команд. Читайте такие запросы перед подтверждением.

## Tools, MCP и skills

Bridge поддерживает tool calling: Claude Code и OpenCode могут читать и изменять файлы, а также запускать разрешённые вами команды. Это проверено с режимом **DeepSeek Reasoner** — его рекомендуется выбирать для агентных задач.

MCP-серверы и skills устанавливаются в самом Claude Code или OpenCode обычным способом. Bridge их не устанавливает и не запускает, но передаёт их вызовы как обычные инструменты. Базовая работа инструментов проверена; отдельная live-проверка именно сторонних MCP-серверов ещё не добавлена.

## Если кнопка Claude Code или OpenCode неактивна

Сначала нужно установить выбранный агент.

### Claude Code

Официальная инструкция установки для Windows: [Claude Code](https://code.claude.com/docs/en/setup).

После установки закройте и снова откройте панель DeepSeek Bridge, затем нажмите `Ctrl+F5`. Кнопка Claude Code станет активной.

### OpenCode

Официальная инструкция установки для Windows: [OpenCode](https://opencode.ai/en/docs).

После установки так же обновите панель через `Ctrl+F5`.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| Панель пишет «Нужен вход» | Нажмите «Войти в DeepSeek» и войдите снова. |
| Диагностика выдаёт ошибку | Повторите вход в DeepSeek. Сессия могла закончиться. |
| Окно выбора папки не видно | Проверьте панель задач Windows или вставьте путь к папке вручную. |
| Кнопка агента неактивна | Установите Claude Code/OpenCode и обновите панель `Ctrl+F5`. |
| Агент открылся не в той папке | Выберите правильную папку в панели и запустите его заново. |
| Модель Expert или V4 Pro недоступна | Это ожидаемо: сейчас доступны Chat, Reasoner и варианты с Search. |
| Панель не открывается | Закройте старые окна Bridge и снова дважды нажмите `START_DEEPSEEK.cmd`. |

## Важно о безопасности

- Файл `deepseek-auth.json` даёт доступ к вашей сессии DeepSeek. Не отправляйте и не публикуйте его.
- Bridge работает только локально, по адресу `127.0.0.1`.
- Программа не сохраняет ваш логин и пароль DeepSeek.
- Не удаляйте папку `.chrome-profile-deepseek`, если не хотите проходить вход заново.

## Для тех, кому нужны ручные команды

Обычному пользователю этот раздел не нужен.

- Запуск панели из PowerShell: `npm run ui`
- Проверка состояния: `npm run doctor`
- Повторный вход: `npm run auth`
- Тест программы: `npm test`
- Адрес API для других программ: `http://127.0.0.1:9655/v1`
